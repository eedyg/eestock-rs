## 0. 结论（先读这一段）

> **① `r` 没有可证明的独立信息；② dcap 本身在日线长周期上有方向一致的弱负 IC，但统计上判「证据不足」。**

**① 关于 `r`（可调参数是否有独立信息）**
1. **`r` 与 `n` 是同一维度的两种参数化**：`r` 的作用几乎等价于把窗口长度换成
   `n′ = 2·EL(n,r)+1`（`EL` = 02-spec §1.3 的有效回看）的 `r=1` 线。
   `n=8, r=1.2` ↔ `n′=7`（ρ=0.9975）；`n=26, r=1.2` ↔ `n′=13`（ρ=0.9821）；`n=60, r=1.2` ↔ `n′=13`（ρ=0.9803）。
2. **近 `r=1` 是「可由 n 复现的冗余区」**：`n=60` 时 `r=1.02`、`n=26` 时 `r∈[0.95,1.02]`、
   `n=8` 时 `r∈[0.85,1.5]`（细网格进一步确认 `[0.9,1.1]` 全在冗余区内）均在
   `ρ_max ≥ 0.99`、分位残差/IQR ≤ 0.05 的冗余判定内（36 个 (n,r) 单元里 **14 个冗余**，逐个见 `tables/sec2_equiv_map_d1.csv`）。
3. **远离 1 的区域只有「部分冗余」或「不可复现」**：多数单元 `ρ_max ∈ [0.95,0.99]`（19/36）——指数权重形状
   无法被任何均匀窗口精确复现；`r ≤ 0.7` 且 `n` 较大时（`n=60`：0.9318/0.9385；`n=26, r=0.5`：0.9458）明确**不可由 n 复现**（权重压在窗口最旧 bar 上，
   退化为长窗价格比式对比）。
4. **冗余是双向的**：`r≫1` 时反过来是 **`n` 冗余** —— `r=1.5` 下 `n=8/26/60` 三条线秩相关 0.9917–1.0000
   （全退化成 1 根 ROC 形态）。⇒ `(n,r)` 实际只有**约 1 个有效自由度**，哪个旋钮冗余取决于所处区域。
5. **正交化后没有增量**：以 `dcap(r=1)`、`BIAS(n)`、`ROC(h)` 为基线，324 个 `(n,r≠1,h,时段)` 单元的偏 IC
   中位数 **−0.001**；**Bonferroni / BH-FDR 均无一个显著**（最强单元 `n=60,r=0.7,h=32,OOS` 偏 IC −0.10，
   p=0.068，7 标的中仅 1 个 |NW t|>2）。
   ⇒ 结论：**没有证据表明 `r` 带来独立信息**（既无证据支持它带来增量，也无证据显示它会损害信息量）——
   其有效维度已被 `n`（更准确地说，被「等价窗口长度 `n′`」）基本覆盖。**本报告不做产品裁决**（`r` 保持可调与否由用户/架构侧定）。

**② 关于 dcap 本身有没有信息**
1. 日线上存在**方向一致的长周期逆势 IC**：`n=60, h=32`（32 根 bar ≈ 1.5 个月）OOS 平均 IC ≈ **−0.23**
   （IS ≈ −0.06 ~ −0.07，符号同为负；`h=32` 全 63 个单元 63/63 为负）；短周期 `h ∈ {1,2}` 的 |IC| ≤ 0.028。
2. **但它经不起统计纪律**：1134 个检验的家族内 **Bonferroni / BH-FDR 均 0 个显著**；
   重叠窗口校正后（`n_eff ≈ n_bars/h`）最强单元的 z ≈ **−1.0 ~ −1.1**（p ≈ 0.29–0.31）；
   面板横截面 NW t（`n=60,h=32,OOS`）仅 **−0.75**（IC −0.046）。
3. **稳定性弱**：日线 OOS 上没有任何单元达到「7/7 标的同号且 |IC|≥0.02」（0/378）；时间片符号一致度中位 0.686
   （纯噪声 ≈0.58）；日线 vs 15m 同号率 **33/216 = 15.3%**（15m 上 |IC| ≤ 0.034，量级可忽略）。
4. **分位分组与 IC 一致**：OOS `h=32` 上最低 dcap 组（G1）中位未来收益 +2.17~+2.49%、最高组（G5）−1.45~−1.77%
   （G1−G5 中位 +4.24%，6/7 标的为正），但 **IS 上该价差符号翻正**，跨期不互证。

⇒ **一句话**：**`r` 几乎没有独立信息（与 `n` 高度冗余、正交化后无显著增量）；dcap 的日线长周期逆势 IC 在方向与分组层面可见，
但在多重比较、重叠窗口、跨标的/跨周期稳定性面前均不成立 —— 判为「证据不足」，本报告不主张 dcap 具备可利用的信息量，
也不主张 `r` 有新增价值。** 本报告不做产品裁决（`r` 是否保持可调由用户/架构侧决定）。

**结论（判定规则在计算前写死：`ρ_max ≥ 0.99 且分位残差/IQR ≤ 0.05` ⇒ 冗余；`0.95 ≤ ρ_max < 0.99` ⇒ 部分冗余；`< 0.95` ⇒ 不可由 n 复现）**
- 日线 36 个 `(n,r)` 单元：**冗余 14 / 部分冗余 19 / 不可复现 3 / 边界 0**；15m 为 14 / 20 / 2（结构一致 ⇒ 与数据频率无关）。
- **冗余区** = `r` 接近 1，且 `n` 越小冗余区间越宽（`n=8`：`r ∈ [0.85,1.5]`；`n=26`：`r ∈ [0.95,1.02]`；`n=60`：`r = 1.02`）。
- **不可复现区** = 大 `n` 且 `r ≤ 0.7`（权重压在窗口最旧 bar，形成长窗价格比式对比，任何均匀窗口都匹配不上）。
- **部分冗余区** = 其余（`0.95–0.99`）——指数权重形状**可近似但不可精确**由 `n′` 复现，残差随 `|r−1|` 与 `n` 增大。

## 7. §4 增量信息（关键）：`r ≠ 1` 有无偏 IC

方法：每 ETF、每时段，把 `A = dcap(n,r≠1,m=3)` 对 `X = [1, BIAS(n), ROC(h), dcap(n,r=1,m=3)]` 作 OLS 正交化，
取残差 `A⊥` 与未来收益的 Spearman（偏 IC）；同时做多元回归 `ret ~ [BIAS, ROC, dcap(r=1), A]` 并给 Newey-West(Bartlett,
lag=max(h−1,1)) 稳健 t。

| 项目 | 结果 |
|---|---|
| 家族规模 | `n(3) × r≠1(6) × h(6) × 时段(3) = 324`；Bonferroni α = 1.54e−4 |
| **BH-FDR(q=0.05) 显著** | **0 个** |
| 全部 324 单元偏 IC 中位数 | **−0.0011**（≈ 0） |
| 最强单元 | `n=60, r=0.7, h=32, OOS`：中位偏 IC **−0.1005**、跨 ETF t = −2.22、p = 0.068；7 标的中仅 **1** 个 \|NW t\|>2 |
| 符号分布 | 偏 IC 为负的单元占多数，但都达不到显著域；正向偏 IC 的最大值仅 +0.06 |

对照（`§4b`，`r=1` 的 DCAP 自身对 `BIAS+ROC` 正交化）：162 个单元的偏 IC 中位绝对值 0.011、最大 **0.067**，跨 ETF t 最大 |t| < 2.3 —— 同样不显著。

## 9. 未覆盖项 / 局限（不静默截断）

1. **标的**：仅 7 只 ETF（既有研究集），未覆盖个股、指数、期货主力连续、可转债。
2. **周期**：日线 + 15m；**未覆盖 5m / 1h / 1w / 1mo**。
3. **参数范围**：`r ∈ [0.5, 2.0]`（ABI 范围）、`n ≤ 250`；**未覆盖范围外的 `r`/`n`**；等价 `n′` 映射仅扫到 250
   （映射表中「外推」项为 0 个，但 `r=0.5, n=60` 的理论 `n′_EL = 117` 与经验 86 差距较大，属模型近似误差）。
4. **收益口径**：只用 close-to-close（无分红调整、无复权处理）；**未做除权/分红核对**（数据源既有口径）。
5. **统计口径**：IC 为 Spearman（秩），未做 Newey-West 逐 ETF 时间序列 t（改用「跨 ETF t + 面板横截面 NW t +
   重叠校正 z」三条互补口径）；`n_eff ≈ n_bars/h` 为保守近似，未做 bootstrap 分块抽样。
6. **多重比较**：按「周期 × 全网格 × 全 h × 全时段」为家族；若按更小家族（如仅 m=3、仅 OOS、仅 h=32）计算，
   FDR 门槛会放宽（例如 21 个检验时 BH 阈值 0.05×1/21 = 2.4e−3，最强单元 p≈0.015 仍不显著）。
7. **未做**：任何策略层检验（阈值/仓位/费率/年化/回撤/胜率/ensemble/ExecutionPolicy）——本任务硬边界。
8. **数据快照冻结**：日线止于 2026-09-09、15m 止于 2026-09-11（快照时点），未取最新 bar。
