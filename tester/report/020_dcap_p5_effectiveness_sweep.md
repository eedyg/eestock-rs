## 0. 结论（一句话）

> **`r ≠ 1` 不带来 `r = 1`（遗留 DCAP）之外的增量**：`r > 1` 在 IS 上显著劣化（21 配对符号检验
> p = 0.001–0.027）、OOS 方向亦为劣（中位 −0.4% ~ −6.0%）；`1 < r ≤ 1.2` 的三线差异化配置最好也只是
> 统计打平（p ≈ 1.0）；`r < 1`（0.90/0.95）虽在 OOS 出现弱正号（收益 Δ中位 +2.2% / +3.5%、MAR Δ中位 +0.059 / +0.099，
> 15/21 胜），但其 **IS 侧不能互证（收益 Δ中位 −0.9% / −1.6%，9/21 胜；MAR 口径仅打平至略优）**，
> 方向自相矛盾、跨 m 单元格排序翻转，且未过多重比较阈值（Bonferroni α = 0.005 下 p = 0.078）
> ⇒ **判为噪声/证据不足，不构成增量证据**。
> 结论：**dcap 的 `r` 保持默认 1.0**（不引入非默认 r）。

**附带的诚实负面发现（决策相关）**：按 SWEEP 纪律冻结的 IS Top-3（`r1.00|m1` / `r1.05|m1` / `r1.20|m1`）
在 OOS 上**均小幅落后买入持有**（中位 Δ收益 −2.4% / −3.2% / −5.4%），且 **IS→OOS 跨组合排序 Spearman ρ = 0.000**
（IS 排名无外推力）。因此本报告**不作任何 m / r 参数的交付推荐**；若要用 dcap 作为交易信号并期望跑赢持有，
需要另起任务并重新设计冻结规则（不得用本报告 OOS 结果反选参数 —— 那正是样本外选择偏差）。

## 5. 核心问题：`r ≠ 1` 是否有增量？

**判据（预先定死）**：① 看 **IS**（选优期）是否有正号；② OOS 一次性对照 `r = 1` 同 m 同标的的**配对差**；
③ 显著性用 **21 配对符号检验** + **配对 bootstrap 中位数 CI**；④ 多重比较（10 个 r 配置并行）用 Bonferroni α = 0.005。

**结论（逐层）**：

1. **`r > 1`（1.02 / 1.05 / 1.20）：明确无增量，方向为劣。**
   - IS：Δ中位 **−4.2% / −7.5% / −8.6%**，逐标的 5/16、4/17、5/16 胜（p = 0.027 / 0.007 / 0.027）。
   - OOS：Δ中位 **−1.8% / −0.4% / −6.0%**，逐标的 8/13、9/12、7/14 胜（p = 0.383 / 0.664 / 0.189）——**无任何一层为正**。
   - 机理与先验一致：`r > 1` 把权重压向最新 bar（`A_k = r^(k−1)`，k = n 最新）⇒ 信号更敏感、**交易数单调上升**
     （m=1：30 → 37 → 59 笔；m=5：15 → 20 → 26 笔）⇒ 更接近"1 根 ROC"（与 `momentum` 范式重叠），换手磨损上升、OOS 收益下降。
2. **三线差异化（只让某一条线加速）：无增量。** 最好的两格（`rs1.20/rm1.00/rl1.00`、`rs1.00/rm1.00/rl1.05`）
   OOS Δ中位 −0.2% / −0.0%、10 胜 / 11 负、**p = 1.000**，即**统计上完全打平**；其余三线差异化配置 OOS Δ中位 −2.7% ~ −5.0%。
3. **`r < 1`（0.90 / 0.95）：OOS 弱正号，但 IS 无法互证 ⇒ 证据不足（不可裁决为增量）。**
   - OOS：收益 Δ中位 **+3.5% / +2.2%**（15 胜 / 6 负）、MAR Δ中位 **+0.0991 / +0.0588**（15 胜 / 6 负），
     收益 bootstrap CI +[0.7%, +6.5%] / [+0.2%, +6.0%]，**p = 0.078**（未过 α = 0.05，更未过 Bonferroni 0.005）。
   - IS：收益口径 Δ中位 **−1.6% / −0.9%**（9 胜 / 12 负，p = 0.664）；MAR 口径 Δ中位 **−0.0075 / +0.0017**
     （9/12 与 **11/10 = 打平**）。即 **OOS 的正号在 IS 侧找不到对应正号**（`r0.95` 最好也只是打平）。
   - 且**同一配置在不同 m 上 IS 排序自相矛盾**：IS MAR 在 m=1 时 `r1.00`(0.1031) > `r0.95`(0.0730) > `r0.90`(0.0550)，
     在 m=5 时 `r0.95`(0.0373) > `r1.00`(0.0050) > `r0.90`(−0.0025) ⇒ 按 IS 冻结**冻不出稳定的 `r<1` 优选**。
   - 按 §1 纪律（选优只在 IS），该方向不会被冻结；用 OOS 正号反推"r<1 有用"即样本外选择偏差。⇒ **判噪声/证据不足**。

**一句话**：`r ≠ 1` 的**每一层**（`r>1`、差异化、`r<1`）都无法在 IS 上给出正号（最好也只是打平）；
OOS 唯一的正号（`r<1`）与 IS 不能互证、不显著、且跨 m 单元格排序自相矛盾 ⇒ **不存在可裁决的增量**。
**建议：`r` 保持 1.0（遗留 DCAP），不引入非默认 r。**

**读法（纪律优先）**：全地貌里"看着最好"的 `r1.00|m5` 在 IS 上排第 6，**必须按纪律弃用**（用 OOS 反选 = 选择偏差）；
但 ρ = 0 同时说明**本任务所用"IS 中位数 MAR 冻结"规则在这个指标族上不具备外推力**——
冻结出的 m=1 组合在 OOS 全部小幅落后持有。这两点是**同一枚硬币的两面**，都必须上报：
① 不因 OOS 改选；② 也不宣称 dcap（60/40 + 全仓 LumpSum）在本宇宙跑赢买入持有 ——
**IS 冻结组合的 OOS 收益落后持有 2.4–5.4 pt（回撤低约 10 pt，MAR 同量级）**。

**统计强度警示（必须带入结论解读）**：7 标的 × OOS 仅 0.5–4.3 年（m=5 组合 OOS 中位仅 15 笔平仓），
样本量小；`dcap` 的"逆势买入"在 512480（半导体，OOS +33.6% 持有）与 518880（黄金，+140% 持有）这类强趋势标的上
表现为踏空（m=1 冻结组合分别 −8.2% 与 +11.6%）。**本报告的"无增量"结论方向一致、可复现，但单格绝对数值置信度低。**

## 12. 残留风险与诚实声明

1. **样本量**：7 标的、OOS 0.5–4.3 年、组合 OOS 中位 15–59 笔 ⇒ 单格绝对数值置信度低；
   本报告的"无增量"结论建立在 **方向一致 + 配对符号检验 + 双跑可复现** 之上，而非单点数值。
2. **IS 冻结规则的外推力**：ρ = 0 ⇒ 该规则在本指标族上不具外推力；本报告**不据此改选参数**，也不据此宣称机制优劣。
3. **多重比较**：主网格 9 组合 + 扩展 27 组合；r 维度的 10 个配置用 Bonferroni 0.005 复核，**无一达标**。
4. **先验不复核**：`dcap8 < −1%` / `dcap12 五年领先` 等先验来自既有研究，本任务未独立复核其绝对结论（只做增量问题）。
5. **未用 HTTP 路径复核**：本任务走 in-process 库调用（同一引擎 + 同一插件字节）。
   平台 HTTP 路径（`test-run` / `workbench runs`）在 P2/P3 已独立验收，二者差异仅在取数/装配层，不影响本结论。
6. **`r < 1` 的 OOS 正号**：如后续有人主张"r<1 有价值"，**必须先在 IS 上重新冻结**（本报告 OOS 已看过 ⇒ 该方向的 OOS 已污染，
   不能再用作裁决依据）——这是本报告留给出题人的唯一"未决"方向（其 IS 证据为：收益口径 9/21 胜、MAR 口径 m≥3 略优 / m=1 明显劣）。
7. **冻结规则强度**：主网格仅 9 组合 ⇒ 冻结 Top-3 覆盖了 1/3 网格；ρ = 0 下"冻结"的统计意义有限 ⇒
   本报告优先用**全网格配对比较**（21 配对 × 10 个 r 配置）而非仅冻结组合下结论。
