  - `D_ceil` = `nBase / #{卫星 bar: ts ∈ [t0,t1]}`（左边界取整桶，**不含**被部分覆盖的左桶）
  - `D_floor` = `nBase / #{卫星 bar: ts ∈ [floor_bucket(t0), t1]}`（**含**被部分覆盖的左桶）
  - 真值必落在 `[D_floor, D_ceil]`（两者之差 = 1 根卫星 bar 的量化，属真渲染不可消除的桶边界效应）
  - 重复取样：`bs ∈ {1, 2, 4}` 各 **3/2/2 次**重复 ⇒ 逐位一致（见 §1.4）
- **交叉测**：`D(15m→30m)`（自洽校验 `≈ D(1m→30m)/D(1m→15m)`）与 `D(1m→15m)`（对照既有表值 12.2）同法测量。
- **旁证法（仅作交叉，不入表）**：K=8 / K=16 **等时窗中位数**（**既有 5 条表值的同一估计器**，260 P0.3 手法）：把两侧覆盖交集按等长时窗切 K 份，逐窗算 `nB/nS`（`nS ≤ 1` 的窗作废），取中位数。

### 1.7 一个**新发现的既有漂移**（登记，不入本轮范围）

30m 的实测锚点会**同时**被 `composeDensity` 用于合成 `15m↔30m`：`composeDensity('15m','30m') = D(1m→30m)/D(1m→15m) = 24.1/12.2 = 1.9754`，而**真渲染实测** `D(15m→30m) = 1.80` ⇒ **漂移 +9.7%**。

根因：既有表值 `1m:15m = 12.2` 是老覆盖窗（09-08→09-14，260）下取的；用**当前**数据同法测得 `1m:15m` = **13.389**（K8/K16 中位一致，见 §1.2 `1m:15m` 段），`24.1/13.389 = 1.800` 恰好吻合。

⇒ 本轮**不改**既有 5 条（ADR/任务书禁令），仅登记为 D2 的**已知漂移风险**：合成 `15m↔30m` 的密度偏高 ~9.7%（对 barSpace 只有 ~10% 偏差，且卫星侧有「≥2 根 + 有界闭环」护栏兜底）。回归测试 `period30mD2.test.ts` 里对合成值只断言「≥ 非 null 且漂移 ≤15%」（宽松护栏），不把它当精确值。
