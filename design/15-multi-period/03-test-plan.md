# 多周期指标同显 — TDD 规格 / 测试计划

> 依据：`01-adr.md`（ADR-022）、`02-spec.md`。**四道硬门禁**（任一不通过即打回）：
> **G1 同步无漂移** · **G2 静默消失防护** · **G3 请求/订阅预算** · **G4 像素级渲染取证**。
> 全部测试先红后绿；反向证据（变异必红）与真实渲染（真身 klinecharts）为强制要求。

## 1. 硬门禁定义

| 门禁 | 判据 | 证据要求 |
|---|---|---|
| **G1 同步无漂移** | ≥20 轮镜像后各实例相对偏移 **0**；跨周期时间跨度误差 **≤1 根高周期 bar**；`syncSuppressed>0` 且无回声循环 | 真实渲染 + 逐轮数值表 + 反向证据（关掉抑制标志 ⇒ 出现回声/漂移即红） |
| **G2 静默消失防护** | 任何"在已有指标 pane 再建指标"的路径都必须走 `addOverlayIndicator`；**人为构造 `isStack=false` 触发** ⇒ 断言/异常必须命中（红） | 变异测试 + `getIndicators({name})` 数量断言 |
| **G3 请求/订阅预算** | 4 周期 × 1 标的：每分钟兜底次数 ≤ 4、WS 订阅数 ≤ 4、初始化 HTTP 次数 ≤ 4（+warmup 合并） | 请求/订阅计数原始日志 |
| **G4 像素级渲染取证** | 每个卫星的指标线**在画布上确实被画出**（像素证据，不只 `getIndicators()`） | 页面截图 + 画布像素采样（**禁用 `getConvertPictureUrl`**，零高 pane 会抛错） |

## 2. 测试清单

### T1 单实例骨架（基准图）
- 基准实例周期 = `periods[0]`；K 线可见；ADR-020 口径成立：`visible ≈ viewport_bars`、`barSpace ∈ [1,50]`、手动缩放后 resize 不重算。
- 反向：把 `barSpaceLimit` 放宽到基准 ⇒ 断言必须红（证明基准未被放宽）。

### T2 卫星实例（隐藏 K 线）
- `candle_pane` 高度 = **0**（`state:'minimize'`、`minHeight:0`），`separator.size = 0`；指标 pane 填满；缩放/滚动后仍为 0。
- 断言 `setPaneOptions({height:0})` **单独使用无效**（红），必须走 `state:'minimize'`（把 P7a 的库事实固化为回归）。

### T3 **G1 同步无漂移**（核心）
- 同周期两实例：`scrollToDataIndex(n)` 后可见范围**逐字段相等**；20 轮镜像后偏移 0。
- 跨周期（1m↔5m / 1m↔15m / 1d↔1w）：对齐后时间跨度差 **≤1 根高周期 bar**；`syncSuppressed > 0`。
- 反向：禁用重入抑制 ⇒ 出现回声（`reentrant` 计数 >0 且范围抖动）⇒ 红。
- 边界：1m↔1w **不可选**（护栏校验拒绝，见 T6）。

### T4 回到最新与手动视口
- "回到最新" ⇒ 所有实例右端对齐（误差 ≤1 根高周期 bar）。
- 手动缩放/平移后 ⇒ **新 bar 到达不得自动拉回**（沿用 ④ 口径：非跟随态不滚动）；各实例均不得被强拉。

### T5 指标继承与 LIVE 段
- 基准勾选 `{MA, MACD, KDJ, BOLL, DCAP}` ⇒ 每个卫星各自渲染同样集合（逐实例 `getIndicators` 非空 + G4 像素证据）。
- DCAP：每卫星 precision 5（4 位 vs 5 位对照）、0 参考线存在且 `y == y(0)`、数据不足断线。
- LIVE 段：进行中桶存在 ⇒ 末段虚线；`1d`（无进行中桶）⇒ **LIVE 段不存在**（一般规则）。
- ⚠️ 依赖未证实项：进行中桶是否随分钟更新（定时探针结论落地后补断言语义说明）。

### T6 配置面与护栏（严格 400 / 默认回退）
- `PUT /api/config/multi_period` 负例：基准 `1mo`；卫星 < 基准；卫星含 `1mo`；含 `1w` 但基准 < `1d`；周期数 >4；`heights` 键不匹配或越界；`indicators` 含未支持项；周期重复 ⇒ **全部 400**。
- `GET` 无键/坏 JSON/越界旧值 ⇒ 回默认（**不 500**）。
- **总 pane 数 >12 ⇒ 拒绝保存并明确报错**（不静默截断）。
- 反向：放宽任一校验 ⇒ 对应负例变红。

### T7 **G2 静默消失防护**
- `addOverlayIndicator`：正常路径生效；`removeIndicator` 后再建；断言非空失败即抛错。
- **变异**：人为在已有指标 pane 上以 `isStack=false` 创建第二个指标 ⇒ 断言必须命中（红），证明我们真的在防这个坑。
- 整改验证：`KlineChart.tsx` / `GridCell.tsx` 不再出现 `createIndicator(..., false)`（grep 断言）。

### T8 数据与预算（**G3**）
- 每实例 `GET /api/kline?period=P&limit=viewport+warmup`；warmup 仅当该实例显示 dcap（`n_l+m−1`）。
- 4 周期 × 1 标的：每分钟兜底 ≤4 次、WS 订阅 ≤4、初始化 HTTP ≤4；`realtimePoll` 按 `(code,period)` 合并、并发闸 3 生效（请求计数证据）。
- **禁止本地聚合**：断言实现中不存在"用 1m 聚合出的高周期"路径（代码级 + 行为级：与后端同桶逐值一致）。

### T8bis **诚实降级与「对齐受限」标注**（口径 5，用户裁决方案 1）
- 构造退化场景（如基准 1m→卫星 1h 且基准缩放至使 `satBS > paneWidth/2`）：
  1. 卫星 `barSpace` = 「能容纳 ≥2 根的最大值」（**不得**等于推导值）；
  2. 卫星**可见 bar ≥ 2**；
  3. **右端对齐**（两侧最右可见 bar 时间戳差 ≤1 根高周期 bar）；
  4. pane 显示「**对齐受限**」角标，hover/点击给出原因（请缩小基准图或改选周期），且 `syncDegraded: true` 与跨度差可从页面/日志读出；
  5. 用户缩小基准图后 ⇒ 角标消失、回到正常对齐（误差 ≤1 根高周期 bar）。
- 反向：把降级实现改成「照用推导 barSpace」（退化为 1 根 bar）⇒ **必须变红**（锁住“不得静默虚假对齐”）。

### T9 布局持久化与 ②③ 契约
- 拖拽每实例高度 → 持久化到 config（防抖写）→ 刷新/重进后保持。
- **保存 dcap 参数 / 切周期 / 切标的 ⇒ 所有实例高度不变**（±1px）。
- 反向：走"重建实例"的实现 ⇒ 高度断言红。

### T10 **G4 像素级渲染取证**
- 每个卫星：画布上采样到指标线像素（DCAP 三线色 + 0 线灰虚线）；**不得**使用 `getConvertPictureUrl`（零高 pane 抛错）。
- 阳性/阴性对照：正确 pane 区域有像素、对照行（y(0)+40px）无像素。

### T11 生命周期与开关并存
- 关闭多周期 ⇒ 完全回到单实例：无残留卫星、无多余 WS 订阅、无多余请求（计数证据）、既有 ①②③④ 行为不变。
- 切换代码/周期 ⇒ 卫星重建正确、不串数据（首末时间戳与值随新 code/period 变化）。

### T12 失败可见
- 任一卫星初始化失败（注入故障）⇒ **可见报错**（不得静默降级为单图）。
- 单卫星 feed 连续失败 ⇒ 退避与观测字段（`pollFailures`）正确，且不影响其它实例。
