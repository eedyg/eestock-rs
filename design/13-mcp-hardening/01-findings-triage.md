## 2. 影响分析（按优先级）

1. **策略研发有效性（最高）**：I-2 未预热使 M15 场景白扔 ~34% 样本、绩效失真；I-3 无 fee 参数
   且固定 LumpSum 口径，会系统性高估收益、并让 DCA 策略只产生 1 笔回合（绩效无意义）。
   → **硬性纪律**：修复并验收前，平台回测绩效数字不得用于任何策略裁决或产品化决策。
2. **研发效率**：I-4/I-5/I-7/I-10 属"每次调用都在交税"类问题（拿不到标的列表、取不到长历史、
   目录查询数十 KB、最大窗口无法端到端校验）。
3. **ABI 与安全**：I-8 影响跨周期策略写法（现只能外部换算参数，属脆弱变通）；I-9 属独立安全议题。

## 3. 需用户拍板的决议清单

| # | 议题 | 架构师建议 |
|---|---|---|
| D1 | I-4 新增标的列表工具 | 新增 `list_symbols`（返回 code/name/类型/注册状态/数据可用区间），与 web `/api/symbols` 同源；MCP 三端口行为对齐 |
| D2 | I-5/I-10 `get_kline` 取数契约 | 增加 `from`/`to`（ISO 日期）；`limit` 上限提升至可配（默认 10000）；超限返回明确错误并提示分段——**不引入游标分页**（复杂度不值） |
| D3 | I-6 周期口径统一 | 采用 **(a) 引擎支持 H1**（数据层与 cagg 已有 1h，成本低、消除双口径）；不建议从 get_kline 摘除 1h |
| D4 | I-8 插件 ABI 增加 `ctx.period` | 作 ABI 小版本修订（与既有 `ctx.bar_at(k)` 备案扩展合并评估）；**ABI 变更须用户批准** |
| D5 | I-7 `strategy_list` 瘦身 | 默认返回摘要（不含源码），新增 `include_source=true` 显式取全量；评估 web 端依赖后再切默认 |
| D6 | I-2/I-3 修复口径 | I-2：明确 warmup 语义（指标预热窗口计入计算、warmup 段样本标记且不计入绩效，或接口层显式预热）；I-3：`strategy_test_run` 增加 fee 参数组（费率/最低费/印花税口径按标的类型）+ `investment_mode`(LumpSum/DCA) + `capital`，与回测工作台口径统一 |
| D7 | I-9 安全 | 本期只做「约束显式化 + 文档化」（loopback-only 为设计约束，ADR-010 内网免认证）；TLS/鉴权/OpenAPI 另立 ADR，不夹带进本批 |
