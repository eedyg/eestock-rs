# ADR-012：交付波次

- 状态：✅ 已定
- Wave 1 数据底座：TimescaleDB schema + 采集服务（注册表/随机轮询/熔断/心跳/当日缺口回填）+ 连续聚合 + 源健康指标 + Web 骨架 + 页面①②③ + MCP 行情/源健康
- Wave 2 质量与告警：tushare 同步 + 质量对照（页面④）+ 告警引擎（页面⑦）+ MCP 质量
- Wave 3 分析：回测引擎 + 工作台（页面⑤）；**并行交易 spike**（chromiumoxide 驱动东财的可行性：登录态/持仓查询/下单三关，产出证据报告，失败则回到用户重新决策）
- Wave 4 交易：券商链路 + 交易面板（页面⑥）+ MCP 交易（独立开关）；券商私有数据（持仓/账户）**交易时实时查**，不常驻采集
- 页面⑧系统设置拆入各波次
