# ADR-005：源选取——逐股随机起点 + 轮询转移 + 心跳模式

- 状态：✅ 已定
- 决策：
  1. **逐股随机起点**：每个标的每个采集周期从健康源池随机抽起始源（HTTP 本就是单码请求，随机起点使负载周期内均摊，防封效果最大）
  2. **轮询式故障转移**：失败按固定顺序找下一个，最多遍历健康源一圈；不重复随机（避免重抽已败源，行为确定、TDD 友好）
  3. **心跳模式**：⚠️ 审查修正——心跳降频**只适用于快照池**（30-60s 保活）；1m K线池当前仅两源（腾讯ifzq/新浪jsonp），**两者均全速**，随机起点在两者间轮转；熔断源从轮转序列摘除；故障当周期内转移、下一周期不再尝试
  4. 同一次单标的拉取内粘住同一源（防跨源微分歧抖动）
- 熔断口径：连续 3 次失败/超时 → 熔断；403/429 → 5s→10s→30s 指数退避；每源 token bucket（默认 1 req/s）+ 随机抖动
