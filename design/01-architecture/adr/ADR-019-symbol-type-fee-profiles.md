# ADR-019：标的类型元数据与按类型推断的费率默认值（D11）

- 状态：**已定**（用户 2026-09-12 批准 D11 立项，并要求"先搜真实 fee 再落库"）
- 背景：`strategy_test_run` / `bt_run_ensemble` 的印花税默认值固定 `0.05%`（股票口径），
  而本平台注册标的**全部为 ETF/LOF**（44 只，无个股）→ 默认值对 100% 标的是错的
  （实测：同一 ETF 同配置，默认口径 pnl 少 50.83 元，差 3.2%）。根因是**缺少标的类型元数据**，
  导致费率无法按类型推断。

## 1. 费率事实（架构师调研，2026-09-12；来源见 §5）

### 1.1 场内基金（ETF / LOF）——二级市场买卖
| 费项 | 标准 | 依据 |
|---|---|---|
| **证券交易印花税** | **不征收（0）** | 《印花税法》第三条对"证券交易"作**列举式封闭定义**：仅"股票和以股票为基础的存托凭证"的转让应税 → **基金/ETF/债券本不在征税范围**（是"不征"而非"免征"） |
| **过户费** | **免收（0）** | 中国结算口径：ETF/LOF/封闭式基金/可转债二级市场买卖免收过户费（**注**：ETF 申赎的"组合证券过户"另收费，属场外环节，不在本平台范围） |
| **交易经手费** | **0.04‰（=0.004%）双边** | 深交所收费标准（2026年1月）："基金 按成交额双边收取 0.04‰"；**债券 ETF、货币 ETF 暂免**。**⚠️ 本平台入库存 `0`**（因佣金为全佣口径，规费已含，叠加即重复计费；`fee_profiles.note` 已写明） |
| **证管费（监管费）** | **不列（0）** | 交易所收费表监管费行仅列 A股/B股/优先股（A股 0.02‰）；基金未列 |
| **佣金** | 券商收，**双向**；默认约万2.5~万3，可协商至万0.5~万1；**单笔不足 5 元按 5 元**（部分券商"免五"已松动） | 券商公示（多家） |

> **口径警示**：佣金有"**全佣**"（已含经手费/证管费等规费）与"**净佣**"（规费另收）之分。
> 平台既有默认 `rate_pct=0.025`（万2.5）按**全佣**口径理解，故对 ETF 而言经手费/证管费
> **不得再叠加**（否则重复计费）。本 ADR 明确该口径。

### 1.2 A股股票（当前无此标的，为将来注册预留）
| 费项 | 标准 |
|---|---|
| 印花税 | **卖出单边 0.5‰（=0.05%）**（2023-08-28 起减半；法定 1‰，财税2023年39号公告减半） |
| 过户费 | **0.01‰（=0.001%）双边**（沪深北统一，券商不可减免） |
| 交易经手费 | A股 **0.0341‰（=0.00341%）双边**（2023-08-28 由 0.0487‰ 下调） |
| 证管费（监管费） | **0.02‰（=0.002%）双边**（代证监会收取） |
| 佣金 | 同上（双向，最低 5 元常见） |

## 2. 决议

| # | 决议 | 内容 |
|---|---|---|
| D11-1 | **标的类型元数据** | `symbols` 表增 `type` 列（枚举：`etf` / `lof` / `stock`，可扩展 `bond_etf`/`money_etf`/`index`）。迁移须幂等、向后兼容（默认值需明确，不得静默错判）。 |
| D11-2 | **费率档案入库** | 新增 `fee_profiles` 表（按 `type` 主键）：`commission_rate_pct`、`min_fee`、`exchange_fee_pct`（经手费）、`regulatory_fee_pct`（证管费）、`stamp_duty_pct`（卖出印花税）、`transfer_fee_pct`（过户费）。按 §1 事实播种；**每行须带注释/来源字段说明口径**（尤其 ETF 的"全佣已含规费 → 经手费/证管费列 0"）。 |
| D11-3 | **默认值按类型推断** | 调用方未显式传 fee 时，`strategy_test_run`/`bt_run_ensemble` 依标的 `type` 查 `fee_profiles` 解析默认值；显式传参优先（向后兼容）。响应回显**显式两段**：`fee.effective`（引擎实际应用参数 + `source`=explicit\|profile\|default）与 `fee.profile`（档案全量事实 + `not_modeled` 未建模清单）——未参与撮合的档案字段（经手费/证管费/过户费）**不得出现在 effective 段**，避免误读为「已计入成本」（D11 验收 013 §11.3 修正）。 |
| D11-4 | **类型分类须可审计** | 44 只现有标的的类型分类须给出**分类依据与逐条清单**（代码前缀 + 名称关键词 + 人工复核），并在报告中列出；不得用未记录的启发式静默分类。分类结果先报告再落库（架构师复核）。 |
| D11-5 | **口径文档化** | `design/07-app-plane/01-mcp.md` / `design/08-backtest/` 写明：ETF/LOF 印花税=0（不征）、过户费=0；股票印花税=卖出 0.05%；佣金为全佣口径（已含规费）。 |
| D11-6 | **不在本批** | 债券 ETF/货币 ETF 的经手费豁免、ETF 申赎（场外）费用、管理费/托管费（净值内已计提）——均不在本批建模范围，但 `type` 枚举须为其留位。 |

## 3. 验收口径

1. 迁移幂等（重复执行安全）+ 向后兼容（旧数据有确定默认）。
2. ETF 标的在**不传 fee** 时：印花税=0、过户费=0；显式传 `stamp_duty_pct=0.05` 时以显式为准（可复现旧行为）。
3. `list_symbols` 返回带 `type`；试算/回测响应回显生效 fee 明细与来源。
4. 股票类型（若构造测试标的）按 §1.2 取默认值。
5. 全量测试绿 + tangle 门禁绿（改文档走 tangle 或 stitch）。

## 4. 影响面

- 修复了"ETF 被多收印花税"的系统性失真（此前所有平台回测绩效对 ETF 均偏低）。
- 为后续注册个股铺路；为"免五/全佣"等券商差异提供可配入口（profile 可按需扩展为按标的覆盖）。

## 5. 来源（调研，2026-09-12）

- 《中华人民共和国印花税法》第三条（证券交易列举式定义，基金/ETF 不在征税范围）、财政部/税务总局 2023年第39号公告（印花税减半至 0.5‰，卖方单边）
- 深圳证券交易所《深交所收费及代收税费标准》（2026年1月）：基金经手费 0.04‰ 双边、A股经手费 0.0341‰ 双边、A股监管费 0.02‰ 双边、债券ETF/货币ETF 经手费暂免
- 中国结算收费标准/代收税费一览表：股票过户费 0.01‰ 双边；ETF/LOF 二级市场买卖免过户费
- 多家券商费用公示（华金/长城/大同/浙商等）：佣金双向、最低 5 元、全佣/净佣口径差异
