## 执行策略
- **按优先级**：① 看板（交互最多、最近 bug 集中）+ ⑤ 回测 先行；再②③④⑦⑧。
- **每页**：e2e(真实浏览器) 覆盖交互+边界+重载；vitest 覆盖纯逻辑(分页批量/snap/校验)与组件状态。
- **补用例参照**：分页批量(1d250/1w150/1mo80/min500)、跨周期 B/S、MA 配置持久、收藏持久+拖拽、周/月<2024、长序列着色、初始金额/日期、删除幂等。

## ⭐ 回归约定（确定性）
**本矩阵产出的所有深测用例 = 永久回归测试，非一次性**：
- vitest 单测（分页批量/snap/校验/幂等/黄金样本）→ 入 `web/src/**/*.test.*`，随 `npm test` 常驻运行。
- playwright e2e（`web/e2e/*-deep.e2e.ts` 等）→ 入仓库，随 `npm run e2e`(真实环境) 常驻运行。
- 发现的缺陷 → 修复 + **转成对应回归用例**(fail→fix→green 固化)。
- 每轮结束须对这些用例对当前环境全绿才收尾；改动后自动复跑把关。
- 临时探针/证据在 `/tmp`，不入库。
