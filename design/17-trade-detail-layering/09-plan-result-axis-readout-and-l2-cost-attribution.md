## 4. ADR-027 D12 —— L2 成本归属口径（架构侧裁定，**核心**）

### 4.0 修订既有裁定（必须先读）

ADR-027 §2.10 **Q9b 原文**：「**不引入**「成本对手方 / lot 归属」列——sim 侧有 FIFO lot 语义、回测侧无（加权平均）；要该列即须在回测引入 FIFO 重算 = **第二事实源**。FIFO 归属规则写入文档即可。」

**本批修订**：用户 2026-09-25 明确要求新增「持仓成本」与「卖出部分盈亏」列 ⇒ 覆盖 Q9b 的「不引入」结论。**但 Q9b 的担忧（第二事实源）继续有效并被本裁定显式消解**：

1. **不引入 FIFO、不引入 lot 归属** ⇒ 不制造「回测侧 FIFO 重算」这一第二事实源；
2. 口径取**与回测侧一致的移动加权平均**（Q9b 已述「回测侧 = 加权平均」）；
3. 实现为 **L2 事实的纯函数派生**（单一实现，前后端同步复用），**display-only**：**不得**回灌绩效、对账、审计或被任何计算消费；
4. 与 L1 的关系由 **I5 恒等式**约束（见 §4.3）⇒ 与既有唯一事实源口径可对账。

### 4.1 问题定性

现「累计盈亏」= **净现金流差**（买 `−(trade_value+commission)`、卖 `+(trade_value−commission−stamp_duty)`），**无成本归属**。⇒ 部分卖出或回合未平仓时，该列显示的是「净投入」而非「盈亏」（买入后为大额负数、卖出后回正、**不含未卖部分浮盈浮亏**）。**这不是算错，是列名与口径不匹配。**

### 4.2 裁定：移动加权平均成本（含费）+ 列改造

**成本归属法 = 移动加权平均成本（moving weighted average，含费）**，按同回合 L2 成交顺序递推；**含费**口径（以 L2 事实字段为准）：

- 买入时：`qty += q`；`cost_total += trade_value + commission`；`unit_cost = cost_total / qty`
- 卖出时：`consumed_cost = q_s × unit_cost`（**unit_cost 不因部分卖出而改变**）；`qty −= q_s`；`cost_total −= consumed_cost`
- 卖出净收入 `= trade_value − commission − stamp_duty`
- 买入无印花税；过户/证管不在 L2 事实字段内（以 L2 为准，禁复算）

**为什么不是 FIFO**：① FIFO 会在部分卖出时把持仓成本**跳到较晚批次的成本**（用户会看到持仓成本"莫名跳变"，违反直觉）；② FIFO 需在回测侧引入 lot 重算 ⇒ 正是 Q9b 所忌的**第二事实源**；③ 移动加权平均在部分卖出后**持仓成本保持不变**，是 A 股券商「持仓成本价」的通行口径，且与回测侧加权平均语义同源。

**列定义**：

| 列 | 口径 | 显示规则 |
|---|---|---|
| **持仓成本**（新增） | 该笔成交**后**的持仓**含费**移动加权单位成本 `= cost_total / qty`（递推见上） | 无持仓 ⇒ `—` |
| **本笔卖出盈亏**（新增） | 绝对值 `= 卖出净收入 − q_s × unit_cost(该笔卖出前)`；百分比 `= 绝对值 / consumed_cost` | 仅卖出行；买出行 ⇒ `—`；格式 `+123.45 (+2.31%)` |
| **累计已实现盈亏**（新增） | 已实现盈亏逐笔累加（买入时不变） | 买出行显示当前累计值（首笔前为 `0.00`）⇒ **不得**再出现"买入即负盈亏" |
| **累计净现金流**（原「累计盈亏」**改名**保留） | 现算法一字不改（`cum_realized_pnl`） | 保留以维持与 L1 的对账可见性 |

> ⚠️ 命名风险：新增的「累计已实现盈亏」与既有 `cum_realized_pnl`（净现金流差）字段名冲突 ⇒ **实现时字段名必须消歧**（建议 `cum_cashflow` = 净现金流；`cum_realized_pnl` 重定义为已实现盈亏，或新增 `cum_realized_pnl_ma`）；表头文案必须与字段语义一致，不得裸用「累计盈亏」。

**列顺序（建议）**：… 金额 / 佣金 / 印花税 / **持仓成本** / **本笔卖出盈亏** / 累计佣金 / 累计印花税 / **累计已实现盈亏** / 累计净现金流 / 来源 / 操作。

### 4.3 恒等式与验收判据

- **I2（既有，不动）**：`Σ(L2 事实字段) == L1` 逐位可对账 ⇒ **本批不改事实字段**（纯派生），I2 输入不变。
- **I5（新增判据；编号避开 02-spec §2 既有 I1–I4）**：对 `status='Closed'` 且**全平**（卖出股数覆盖全部买入股数）的回合：**末笔「累计已实现盈亏」== L1 `pnl`**（容差 = 既有 `rt_reconcile.tolerance` 相对口径 `tol × max(1,|l1|)`）。
  - 数学依据：L1 `pnl` = 回合现金流差 = `Σ买(–含费成本) + Σ卖(+净收入)`；移动加权递推在**无剩余持仓**时恰为该值（全部成本已被卖出消耗完）。
  - **不成立必须显式解释，禁止放宽容差**。
- **I6（新增判据；2026-09-26 由独立复验更正字面口径）**：① **首笔卖出之前**的所有买入行 `cum_realized_pnl === 0`（防「净投入」伪装，不得出现负的净投入）；② **买入不改变**累计值（买入行值 == 其前一笔卖出行值）⇒ **首笔卖出之后**的买入行可正可负。
